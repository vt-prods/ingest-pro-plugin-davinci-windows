# Ingest Pro Resolve — plugin for DaVinci Resolve Studio

Ingest Pro Resolve builds an organised multicamera timeline directly inside DaVinci Resolve Studio, live, from the recording time of every clip.

This is the official Windows release repository. The installer is distributed through [GitHub Releases](https://github.com/vt-prods/ingest-pro-plugin-davinci-windows/releases/latest); the plugin source code is not included here.

## What it does

- Detects and groups footage by camera, each camera on its own track.
- Keeps the real recording times and the gaps between clips.
- Synchronises cameras by analysing their audio.
- Optionally applies colour labels, closes inactive gaps, creates one track per clip and leaves out the formats you choose.
- Builds into a new timeline, or into the one you have open without touching your clips.

## Requirements

- Windows 10 or 11 (64-bit).
- DaVinci Resolve Studio 20 or later. The free edition of DaVinci Resolve does not load Workflow Integration plugins.
- Internet connection for licence activation and periodic subscription validation.

## Install

Run the installer and restart DaVinci Resolve Studio. The plugin opens from **Workspace › Workflow Integrations › Ingest Pro Resolve**.
